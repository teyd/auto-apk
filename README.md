# auto-apk

Unofficial [Morphe](https://github.com/MorpheApp)-patched builds of YouTube, Reddit, X,
Instagram, Gboard, Discord, TikTok and Twitch, in one rolling
[`latest`](../../releases/tag/latest) release.

> [!WARNING]
> Modified third-party apps, not affiliated with their publishers or Morphe. Use at your own risk.

Install with [Obtainium](https://github.com/ImranR98/Obtainium): add this repository once per
app with an asset filter such as `^youtube-`. YouTube needs
[MicroG-RE](https://github.com/MorpheApp/MicroG-RE).

Configuration: [`auto-apk.json`](auto-apk.json). Development: [AGENTS.md](AGENTS.md).
